# Calendar Example

[`/examples/integration-walkthrough`](./integration-walkthrough/README.md) is the single example surface. The
typography-led field guide connects product needs to live exhibits for bounded virtualization, read-only use,
product-owned cards, availability, drag/create, zoom, horizontal and vertical overlap, hover reveal, preloading,
late-data stability, focused creation, visual anchors, React integration, and motion.

The main demo links directly to the guide. Every article calendar imports `quno-calendar`, the same public entrypoint a
consumer uses, and later exhibits mount lazily near the viewport.

Primary narrative: [`IntegrationWalkthrough.tsx`](./integration-walkthrough/IntegrationWalkthrough.tsx).
