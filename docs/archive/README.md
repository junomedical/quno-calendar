# Field guide archive

The pre-homepage field guides are available in the demo at `/docs/archive`, with one route per product:
`/docs/archive/infinite-calendar`, `/docs/archive/datepicker`, `/docs/archive/date-input`,
`/docs/archive/timepicker`, and `/docs/archive/date-parser`.

Their copied editorial source, examples, recipes and styles are in [demo/archive](../../demo/archive/README.md),
snapshotted from commit `9013d1c` on 20 October 2026. Current guides remain in `demo/guide` at `/docs`.
The snapshot uses the current public library; it is an editorial archive rather than a historical package build.
